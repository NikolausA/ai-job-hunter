# Development Plan (План разработки)

Документ описывает цели проекта, этапы разработки, порядок работы по спринтам и критерии готовности.
Используется как основа для планирования, контроля прогресса и корректировки курса.

## 1. Цели проекта

Главная цель

Создать платформу AI Job Hunter — сервис, который помогает соискателям эффективно управлять профилем, вакансими и взаимодействием с работодателями.

Подцели

Единый API-слой через tRPC.

Типобезопасность на всех уровнях: схемы Zod, Prisma, App Router.

Интуитивный интерфейс c Tailwind и React.

Хранение данных в PostgreSQL.

Возможность авторизации и персонализации.

Модульная архитектура (FSD + server modules).

Качественное покрытие тестами.

## 4. Критерии готовности (Definition of Done)

Каждая задача считается завершённой, если:

Реализована полностью.

Пройдены unit-тесты.

Пройдены интеграционные тесты (если применимо).

Линтер не выдаёт ошибок.

Добавлены необходимые комментарии.

Внесены изменения в документацию (если требуются).

Сделан commit по Conventional Commits.
